# AYORAI Shield Research Council Map

This is a **research watchlist**, not a claim of affiliation or collaboration. It identifies institutions and researchers whose public work should continuously inform Shield.

| Region | Institution | Public research direction | Shield relevance |
|---|---|---|---|
| USA | MIT CSAIL | contextual agent security; autonomous cyber defense | runtime defense |
| USA | Carnegie Mellon / SEI / CyLab | AI incident response; cyber autonomy | detection, response, autonomous defense |
| USA | Stanford | agent identity, authentication, authorization, delegation | capability security |
| USA | UC Berkeley CLTC | agentic AI risk management | governance and controls |
| USA | NIST | adversarial ML taxonomy and AI risk management | threat taxonomy |
| Europe | ETH Zürich | AgentDojo and agent security evaluation | benchmarks |
| Europe | Oxford GCSCC | security of AI / AI for security / AI-enabled threats | system-level threat model |
| Europe | Cambridge | AI Agent Index and agent safety transparency | evidence and disclosure |
| China | Tsinghua IIIS | secure/robust AI, privacy, distributed LLMs | secure infrastructure |
| China | Shanghai Jiao Tong | AI agent security governance | lifecycle controls |
| China | Nanjing University SecLab | intelligent-agent security, fuzzing, vulnerability mining | offensive testing |

## Operating rule

Shield should track publications, benchmarks, vulnerabilities, standards and open-source defenses from these research ecosystems. New findings should become one of:

1. a threat-model update;
2. a regression test;
3. a benchmark;
4. a defensive control;
5. a documented limitation.

No external institution or researcher is represented as endorsing AYORAI Shield.
