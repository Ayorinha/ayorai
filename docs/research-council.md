# AYORAI Shield Research Council Map

This is a **research watchlist**, not a claim of affiliation, endorsement or collaboration. It identifies public research ecosystems whose findings should continuously inform Shield.

| Region | Research ecosystem | Shield relevance |
|---|---|---|
| USA | NIST | agent identity, authorization, adversarial ML, control overlays |
| USA | MIT CSAIL | contextual agent security, deterministic defenses |
| USA | Carnegie Mellon / SEI / CyLab | AI incident response, cyber autonomy |
| USA | Stanford | authenticated delegation, agent identity and accountability |
| UK | NCSC / GCHQ | federated agents, trusted communication, autonomous cyber defense |
| EU | ENISA | multilayer AI cybersecurity and standardization |
| Switzerland | ETH Zürich | AgentDojo and AI security evaluation |
| UK | Oxford / Cambridge | AI cybersecurity and agent transparency |
| Canada | CSE / NRC / Canadian AI Safety Institute | frontier-AI risk and multilingual agent evaluation |
| Australia | ASD / ACSC | agentic-AI harness security, least privilege and operational assurance |
| Singapore | CSA / GovTech / IMDA | AI Agents Sandbox and agentic-AI security |
| Japan | NICT / IPA | AI-enabled cybersecurity, next-generation cryptography, AI security practice |
| South Korea | KISA | AI security threat classification, red teaming and mitigations |
| China | Tsinghua / Shanghai Jiao Tong / Nanjing University SecLab | secure AI, agent governance, fuzzing and vulnerability research |

## Operating rule

New publications, benchmarks, vulnerabilities and standards should become one of:

1. a threat-model update;
2. a regression test;
3. a benchmark adapter;
4. a defensive control;
5. a documented limitation.

No external institution or researcher is represented as endorsing AYORAI Shield.
