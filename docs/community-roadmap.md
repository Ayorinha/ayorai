# Community Roadmap

AYORAI is intentionally built as a real open-source engineering project.

## Community tracks

### Agent Engineering
Planner, router, specialized agents and execution lifecycle.

### AI Safety
Prompt-injection defense, policy evaluation, auditability and adversarial testing.

### RAG
Retrieval interfaces, provenance, source validation and evaluation.

### MCP Governance
Tool allowlists, permissions, execution boundaries and safe adapters.

### Security Research
Threat modeling, CodeQL, dependency monitoring and responsible vulnerability disclosure.

## How the community can help

Contributors can propose ideas in GitHub Discussions, implement open issues, review pull requests and contribute documentation or tests.

No contribution is created solely for an achievement. Project activity should correspond to genuine engineering work.
