## [0.2.0] - 2026-09-28

### Added
- Agentic framework foundation with orchestration, safety, memory, RAG, MCP and governed tools.
- AYORAI Shield deterministic security control plane.
- Prompt-injection and sensitive-data boundary checks.
- Tool authorization and tool-definition integrity controls.
- Audit and policy primitives with automated tests.
- Threat-model, security-architecture and evaluation documentation.
- Python 3.11–3.13 CI with Ruff, mypy, pytest and pytest-cov.
- Coverage reports published as GitHub Actions artifacts.

### Changed
- Repository structure and contribution workflow documented for open-source development.
- Package metadata expanded for package discovery and repository navigation.

### Security
- Security claims and non-claims are documented explicitly.
- External/adversarial validation remains tracked separately from deterministic unit tests.
