# AYORAI — Agentic Intelligence & AI Safety

AYORAI is an applied AI engineering laboratory focused on reliable agentic systems, RAG, MCP, tool orchestration and AI Safety.

## Vision

Build modular AI agents that can reason, use tools, retrieve knowledge and operate under explicit safety controls.

## Architecture

- **Agents** — specialized autonomous capabilities
- **Orchestration** — coordination, routing and execution
- **Memory** — short- and long-term context
- **RAG** — grounded knowledge retrieval
- **MCP** — standardized tool/context integration
- **Safety** — policy enforcement, validation and agent defense
- **Tools** — controlled external capabilities

🚧 Foundation phase — architecture being rebuilt from scratch.
